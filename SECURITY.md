# Security Policy

## Prototype status

Home Inventory is currently a Phase 0 usability prototype. It uses sample data and is not ready to hold real inventory, customer, payment, or business records.

Do not deploy it publicly or use it as a system of record until authentication, persistent storage, authorization boundaries, backups, dependency review, and production security testing are complete.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If it is unavailable, open an issue requesting a private contact channel without including exploit details or sensitive information.

Include:

- The affected version or commit
- Reproduction steps
- Expected and observed behavior
- Potential impact
- Any suggested remediation

Please avoid accessing, changing, or retaining data that does not belong to you while investigating a report.

## Supported versions

Only the latest commit on the default branch is considered for security fixes during the prototype phase. No released version is currently supported for production use.
