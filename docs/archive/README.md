# Historical Documents

The files in this directory record earlier planning, prototype, and retest work. They are retained for decision history only and are not current operating instructions.

Current documentation lives one level up and in the repository README. When an archived document conflicts with current code or documentation, the current documentation and tested implementation take precedence.

- `DELIVERY_SUMMARY.md` — original planning handoff
- `IMPLEMENTATION_GUIDE.md` — proposed MVP build sequence
- `IMPLEMENTATION_PLAN.md` — earlier product/CSV milestone plan
- `INVENTORY_SYSTEM_PLAN.md` — original system design proposal
- `QUICK_REFERENCE.md` — pre-production phase checklist
- `SAFARI_RETEST.md` — historical Safari authentication retest notes
